# 真实论文阅读体验检查 · 2026-09-18

## 范围与方法

以普通读者的操作顺序，使用已安装的签名阅读预览版和已配置的真实模型，先完成操作、保存截图，再查看实现。共检查三篇论文的五段材料，并非完整通读三篇论文，也不是人类受试者研究或阅读速度基准。

材料直接在 macOS 预览中打开，通过选择文字、复制、Slipstream「读取已复制的英文」进入阅读卡片。未用预设模型输出替代这一轮体验。局部选择产生的首尾残句在个别段落中手动删除。

| 材料 | 位置 | 实际任务 |
| --- | --- | --- |
| [Attention Is All You Need](https://arxiv.org/abs/1706.03762) | 第 1 页摘要 | 翻译、术语解释、保存及编辑知识卡片 |
| 同上 | 第 4 页 §3.2.1 | 公式输出、提取 Q/V 定义、留下及回查 |
| [Adam: A Method for Stochastic Optimization](https://arxiv.org/abs/1412.6980) | 第 2 页 Algorithm 1 | 算法公式、切换论文、符号搜索 |
| [Double/Debiased Machine Learning](https://arxiv.org/abs/1608.00060) | 第 2 页 §1.1 首段 | 术语筛选、手动划词、数学解释 |
| Attention Is All You Need | 第 5 页多头注意力段落 | 重启应用后，跨页回查前页保存的 Q |

预览版使用独立的 `com.slipstream.reading-preview` 身份。此次检查前的本地预览包含尚未发布的本文速查功能，不能将本报告解释为公开版 v1.1.0 已具备或已通过这些能力。

## 第一轮实际结果（修复前）

### 已跑通

- 复制英文原文，生成中文阅读卡片，展开解释，保存到本机知识卡片并编辑笔记。
- 在 Attention 中留下 Q、V 的定义和原文依据，在 Adam 中留下 β1。重新启动应用后仍在。
- 本文速查区分 Attention（2 条）、Adam（1 条）、DML（0 条）；未点击「留下」的候选不自动进入持久库。
- 重启后用 Attention 第 5 页的新卡片回查第 4 页留下的 Q，显示「本文定义 · 本地速查」及原文依据。未进行网络抓包，因此不据此宣称测量过零网络请求。
- 第 4 页的缩放点积注意力公式正确重建为数学排版；另一些公式未达到同等质量。

## 验证边界

- 本轮没有完成原生系统截图 → OCR → 模型的端到端验收。自动化热键/拖选未得到可靠截图，不能据此判断用户的系统权限或快捷键本身存在故障。
- 浏览器 PDF 空白、原生粘贴偶发超时属于本轮工具限制，不作为 Slipstream 产品问题。
- 未验证所有论文、所有模型、长时间阅读或新用户首次配置。
- 本地留下了三个名称带「9月18日体验测试」的论文目录，以及一张注明体验测试来源的知识卡片，供复测使用。

## 修复与复测

本节只记录本轮实际执行并检查的修改，第一轮证据保留原状。

- 搜索单独容忍 PDF 展平的下标：`β1`、`β₁`、`\beta_1` 均可找到同一搜索结果。持久化身份、去重和精确回查仍区分数学对象；例如 `x`、`X`、`x_i` 不合并。
- 已保存条目排在候选前；搜索同时过滤候选，只展示相关结果。搜索期间隐藏「全部留下」，避免把未显示的候选一并保存。
- 用户主动打开本文速查时，首次创建的窗口获取焦点。普通翻译卡片仍保留原有展示方式。
- 所有短行内公式隐藏滚动条装饰，长公式仍能横向滚动。
- DML 复测还发现术语按钮直接显示 `\sqrt{N}` 的 LaTeX 源码；按钮标签现使用现有的安全数学渲染器。增加了修复前失败、修复后通过的原生检查。
- 划词入口在长段落、展开原文、150% 放大下的原生几何检查均通过，发送的词句范围也正确。实际重新拖选 `nuisance parameter` 后按钮立即可见，点击后真实模型解释成功。本轮未改变其布局。

复现命令：在 `slipstream` 目录执行 `npm run check:reading-usability`。这是使用确定性模型输出的原生 Electron 回归检查，与上面的真实模型体验分开记录。修复前五项失败：首次焦点、两种下标搜索、无关候选遮挡、短公式多占 15 像素滚动条；修复后均通过。相关的本文速查、数学渲染回归及 ESLint 也通过。

- DML 真实输出提议 3 条本文定义；搜索 η₀ 后 [只显示相关的一条候选](28-dml-candidates-filtered.png)，没有自动保存。
- 主界面已激活时，[首次创建速查窗口](23-reference-first-open.png) 获取焦点；从阅读卡片打开亦一次进入。从后台刚唤起应用时仍观察到先激活、再操作的情况，不能宣称所有首击场景已经解决。
- 同一 DML 段落的 [行内公式](26-dml-inline-math-fixed.png) 没有多余滚动条。最终补丁中的 [术语标签](29-dml-term-math-fixed.png) 显示排版后的数学字符。
- 模型再次处理同一段落时，术语译名和候选仍会变化，nuisance parameter 仍未自动入选。UI 修复不代表术语筛选质量已经解决。
- 最后一次 root-N 解释还暴露出内容严谨性问题：[实际输出](30-dml-explanation-quality.png) 把收敛速度、非退化极限分布、方差衰减混在同一段概念定义中，容易让初学者以为它们等价。一般 root-N 一致性要求误差为 `O_p(N^{-1/2})`；存在非退化极限分布是更强的性质，方差结论还需要矩条件。这个审阅判断依据 [David Pollard 的 Yale 讲义 §1.2.2–1.2.3](https://www.stat.yale.edu/~pollard/Courses/618.fall2010/Handouts/Heuristics.pdf) 对收敛速率与极限分布的区分。排版成功不能当作概念解释正确的验收标准。
- 最后再次触发系统截图，应用确实启动原生框选进程；当前界面工具未提供可操作的选择器窗口，未完成框选。已有设置界面显示「屏幕录制权限：已允许」。超时/取消后仍出现笼统的权限提示，不能用这个提示断定系统权限未授权。

## 产品判断与下一轮优先级

本文速查在跨页、跨天阅读中有实际价值：重启后能够从新段落找回前页确认的定义及出处。本轮尚不足以把产品视为可靠的数学论文阅读助手。

1. 优先验证公式输入保真与核对流程。Adam 的帽子丢失会改变数学对象；应让读者能对照原文发现损坏，并完成真正的截图公式路径验收。
2. 用陌生材料持续评估术语筛选与解释严谨性；区分一般定义、常见充分条件、本文已有结论及额外背景。评价是否帮读者解决障碍，允许零候选，不能把「返回若干术语」当作成功。
3. 减少换论文时的归属误操作和重复提取；改善取消/超时提示，以及从后台唤起后的首击行为。
