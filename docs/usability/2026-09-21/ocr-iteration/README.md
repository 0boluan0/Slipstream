# 公式识别与核对改进 · 2026-09-21

在同一张真实桌面截图上比较已发布的 1.2.0 代码与 1.2.1。测试输入只包含截图像素，不向识别器提供论文文本或正确答案。改动后结果没有经过手工校正。

| 问题 | 1.2.0 | 1.2.1 |
| --- | --- | --- |
| 独立 α、θ | 被正文 OCR 读成 a、0 | 专用组件根据像素恢复为希腊字母 |
| 第二个偏差校正公式 | 出现原图没有的点号 | 不再出现该点号 |
| 公式后的冒号 | 重复 | 正常保留一次 |
| 1st、2nd | 被包成数学片段 | 作为正文交给翻译 |

[原始屏幕像素](adam-screen.png)、[改动前](before.txt)、[改动后](after.txt)、[全部像素回归](pixel-regressions.json)、[测试元数据](results.json)。

根因与修正：固定像素留白随截图尺寸改变相对布局，现改为按图像宽度计算；部分独立希腊字母的布局分数刚好低于原阈值，现对较弱且紧凑的候选执行专用识别，并只保留高识别置信度的希腊符号结果。公式框的额外纵向扩张会带入相邻行像素，已去除。普通 OCR 可把公式及冒号放在同一个文字框中，遮罩后又识别一次该冒号，合并时现在按原文字框关系去重。序数只在明确识别为文本后缀时还原为正文。

核对页支持点击公式定位到编辑器的对应 LaTeX，原图在编辑框上方，可放大滚动；底部可直接提交校正内容翻译。截图页的校正入口在核对阶段可用，切换页面不会覆盖草稿。

回归覆盖三篇论文、额外公式裁剪、真实桌面截图及放大版本、矩阵、真实导数点号、纯正文和含序数/年份/普通字母的正文。测试还验证确认前不调用翻译、缺少模型和取消，以及点选公式、对照原图与草稿保留。运行：`cd slipstream && npm run check:formula-ocr && npm run check:reading-pins`。

这些是有限样例，不代表普遍准确率。低质量截图、复杂布局或未检测到的符号仍可能错误，核对步骤继续保留。安装包与原生完整流程的验收单独记录。
