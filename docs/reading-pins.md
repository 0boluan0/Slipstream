# 专业阅读与本地卡片

Slipstream 帮助读者解决当前选区里的一个问题，查懂后继续读。

## 一次阅读

按首页显示的截图快捷键，拖出不懂的词句、短段落、公式或小块图文。公式旁保留几行必要说明，避免截断句子。松开后显示中文阅读卡片；Esc 取消。粘贴局部英文也能进入同一条阅读流程。

中文先显示，英文对照按需查看。点击推荐术语，或在英文中选词，查询“概念是什么”和“放在这段里”。没有合适术语时只显示译文。模型提供的原文依据可以展开核对，来源标记不保证解释正确。

浮窗可移动、缩放、置顶、收起和独立关闭。看懂后关闭即可继续读。

## 图片与公式

图片阅读启用后，选区交给配置的图片服务；截图、翻译与解释共用这套 API。旧配置与基础翻译在 Mac 可继续使用本机文字和公式识别，再核对并翻译。

LaTeX 在本机排版，复制和保存时保留源码。图像识别可能漏符号或误读复杂结构；在“截图”页核对原图，按需重新框选或校正。上下文不足时，补上必要说明再查。

## 本地卡片

想留下概念时点击“存为卡片”。默认位置是系统文稿目录的 `Slipstream/术语卡片/`。每张 Markdown 卡片包含解释、原文、本段用法与个人笔记，可在卡片盒搜索、编辑、建立关联与反向关联。

同一术语在完全相同的原文中再次查询时，可以读取已保存的本地解释；不同原文重新查询。大小写与数学 Unicode 字形分别保留。外部编辑造成版本冲突时，应用保留输入并提示重新载入。

卡片只在主动保存后写入。关闭临时浮窗不会删除已保存文件。文稿是否同步取决于系统设置。

## 本文速查

[本文速查](./reading-references.md) 可按论文记住符号、缩写和本文约定，保留原句依据及同名不同义。候选由读者决定是否留下，也可手动记录、搜索和编辑。

保存卡片与建立本文速查都是可选动作，不增加随手查的前置步骤。

## 开发检查

`npm run check:reading-pins` 覆盖文本契约、Markdown 存储、独立窗口、数学排版与取消。原生检查使用临时目录、自拟输入和固定回复，验证程序行为。在线内容与实际桌面操作需要分别核对。

详见 [开发说明](../slipstream/README.md) 与 [隐私说明](./PRIVACY.md)。
